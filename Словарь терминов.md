# Словарь терминов (Глоссарий)

## Определения

| Термин | Определение | Формат | Правило верификации | Синоним |
| --- | --- | --- | --- | --- |
| Врач-специалист | Врач узкой специальности (кардиолог, невролог, офтальмолог и т.д.). К части специалистов можно записаться только по направлению | | | Узкий специалист |
| Диагноз | Заключение врача о заболевании пациента, записанное в ЭМК | Код и название по МКБ-10 | Код есть в справочнике МКБ-10 | |
| ЕГИСЗ | Единая государственная информационная система в сфере здравоохранения. Принимает от поликлиники медицинские документы в виде СЭМД и сведения о сотрудниках (регистр медицинских работников), передает поликлинике справочники НСИ | | | |
| ЕСИА | Единая система идентификации и аутентификации (Госуслуги). Через нее пациент входит на портал поликлиники | | | Госуслуги |
| Заведующий отделением | Врач, который руководит отделением и составляет расписание врачей отделения | | | |
| Запись в ЭМК | Сведения о приеме, которые врач вносит в медицинскую карту: жалобы, анамнез, результаты осмотра, диагноз, назначения | | Содержит диагноз; подписывается врачом, проводившим прием | Протокол осмотра |
| Запись на прием | Закрепление свободного слота в расписании врача за пациентом | Пациент, слот, тип приема, статус: запланирована, отменена, состоялась, неявка | На один слот не более одной активной записи | |
| Инфомат | Сенсорный терминал в холле поликлиники, через который пациент записывается на прием и печатает талон | | | |
| Кабинет | Помещение поликлиники, в котором врач ведет прием. Кабинет задается в рабочей смене, поэтому в разные дни врач может принимать в разных кабинетах | Номер кабинета | | |
| Лист ожидания | Очередь пациентов, которым не хватило свободных слотов к врачам нужной специальности. Когда слот освобождается, ПолиКлик предлагает его первому пациенту в очереди | | | |
| Льгота | Право пациента получать лекарства по льготному рецепту (ПРАВ25) | Категория льготы, срок действия | Действует на дату выписки рецепта | Льгота на лекарственное обеспечение |
| Медрегистратор | Сотрудник регистратуры: прикрепляет и открепляет пациентов, записывает их на прием при личном обращении и по телефону | | | Регистратор |
| МКБ-10 | Международная классификация болезней 10-го пересмотра. Справочник кодов диагнозов | Латинская буква, две цифры, необязательно точка и цифра (например, J06.9) | Соответствует шаблону `[A-Z]\d{2}(\.\d)?` | |
| Направление | Документ, которым врач направляет пациента на консультацию к специалисту, исследование или анализ | Номер, вид, куда направлен, дата выдачи, срок действия | Не просрочено на дату записи | |
| Неявка | Пациент не пришел на прием, на который был записан | | | |
| НСИ | Нормативно-справочная информация: единые справочники (МКБ-10, специальности, должности). Поликлиника загружает их из федерального реестра НСИ в составе ЕГИСЗ | | Вручную не редактируется (ПРАВ22) | Справочники |
| ОМС | Обязательное медицинское страхование. Государственная система, гарантирующая застрахованным гражданам бесплатную медицинскую помощь | | | |
| Отделение | Подразделение поликлиники, объединяющее врачей по профилю (терапевтическое, хирургическое и т.д.) | | | |
| Открепление | Прекращение прикрепления пациента к поликлинике (при переезде, смене поликлиники, смерти) | | | Снятие с учета |
| Пациент | Гражданин, который обращается в поликлинику за медицинской помощью | ФИО, дата рождения, полис ОМС, СНИЛС, адрес, телефон | Полис ОМС действует | Больной |
| Полис ОМС | Документ, подтверждающий право гражданина на бесплатную медицинскую помощь по ОМС | Единый номер полиса (ЕНП) — 16 цифр | Ровно 16 цифр; полис действует по данным ТФОМС | Полис обязательного медицинского страхования |
| Прием | Очная консультация пациента врачом, фактически состоявшаяся по записи | Дата, время начала и окончания, врач, пациент | Проводится только по записи со статусом «запланирована» | Посещение, визит |
| Прикрепление | Закрепление пациента за поликлиникой и участком по заявлению пациента | Пациент, поликлиника, участок, дата прикрепления | Проверен полис ОМС | Постановка на учет |
| Рабочая смена | Часы работы врача в одном кабинете в определенный день. ПолиКлик нарезает смену на слоты по длительности приема для специальности (ПРАВ9) | Врач, кабинет, дата, время начала и окончания | Смены одного врача не пересекаются; смены разных врачей в одном кабинете не пересекаются (ПРАВ26) | Смена |
| Расписание | План работы врача на период: рабочие смены, разбитые на слоты | Врач, период, смены | Смены одного врача не пересекаются | График приема |
| Слот | Интервал времени в рабочей смене врача, на который можно записать одного пациента | Врач, кабинет, дата, время начала и окончания | Находится внутри рабочей смены, кабинет тот же, что в смене; длительность задана для специальности (ПРАВ9); слоты одного врача не пересекаются | Ячейка расписания |
| СНИЛС | Страховой номер индивидуального лицевого счета. Используется для идентификации пациента, в том числе через ЕСИА | 11 цифр в виде XXX-XXX-XXX YY | Последние две цифры это контрольное число | |
| СЭМД | Структурированный электронный медицинский документ, который передается в ЕГИСЗ | XML на основе HL7 CDA R2 | Проходит проверку схемой документа | |
| Табло электронной очереди | Экран в холле у группы из 3–4 кабинетов. ПолиКлик показывает на нем, какого пациента и в какой кабинет вызвали | Номер записи вызванного пациента, номер кабинета | Без ФИО и других персональных данных пациента (152-ФЗ) | Табло |
| Талон | Подтверждение записи на прием, которое пациент получает на портале, в инфомате или в регистратуре | Номер записи, врач, кабинет, дата и время | | |
| Тип приема | Вид приема по цели обращения | Одно из значений: первичный, повторный, по направлению | | |
| ТФОМС | Территориальный фонд ОМС. Ведет реестр застрахованных граждан, подтверждает действие полиса и принимает сведения о прикреплении к поликлиникам | | | Система ОМС |
| УКЭП | Усиленная квалифицированная электронная подпись. Ею врач подписывает записи в ЭМК | Сертификат, выданный аккредитованным удостоверяющим центром | Сертификат действует на дату подписи | Электронная подпись врача |
| Участковый врач | Терапевт, который ведет пациентов своего участка и направляет их к специалистам | | | Врач-терапевт участковый |
| Участок | Территория, жители которой прикрепляются к одному участковому врачу | Номер участка | | |
| Учетная запись | Вход сотрудника в ПолиКлик. Роль в учетной записи задает права доступа | Логин, роль, признак активности | Одна учетная запись на сотрудника | |
| Электронная очередь | Порядок, в котором врач вызывает в кабинет пациентов, записанных к нему на сегодня: по времени слотов. Отмечаться о приходе не нужно. ПолиКлик показывает вызов на табло | Записи врача на сегодня, отметка о вызове | В очередь попадает только запись на сегодня со статусом «запланирована» | |
| ЭМК | Электронная медицинская карта это история болезни пациента в электронном виде. Состоит из записей врачей о приемах | | Одна карта на пациента | Медицинская карта, история болезни |
